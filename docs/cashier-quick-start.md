# PayID Scanner -- Quick Start

## How to scan a code

1. Click into the PayID code field.
2. Place the customer's slip flat under the camera.
3. Press **F8**.
4. The code appears in the field automatically.

That's it -- nothing else to click or type.

## What the sounds mean

- **Success sound** -- the code was read correctly and is already in the
  field. Double check it matches the slip, then continue as normal.
- **Failure sound / "SCAN AGAIN"** -- the scan wasn't confident enough. Just
  press F8 again. If it fails more than 2-3 times in a row, straighten the
  slip and make sure it's fully inside the camera's view.

## If something looks wrong

- **Nothing happens when you press F8** -- check the menu bar (top of the
  screen) for the PayID Scanner icon. If it's missing, tell your manager --
  don't try to fix it yourself.
- **The code doesn't match the slip** -- never submit a code you haven't
  visually checked against the slip. Press F8 to scan again if it looks
  wrong.
- **Anything else unusual** -- stop and tell your manager rather than
  troubleshooting on your own.
